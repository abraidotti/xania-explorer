    Weapons by level and class¶

    Which weapons a character can find and wield at each level from 1 to 91, how good they are, and whether some classes get a worse deal.

    62% of weapons are usable by level 30¶

    Of 420 obtainable weapons, 259 become usable by level 30. Up to then each 5-level band brings about 43 new weapons; after it, about 12, and the thinnest band (71–75) has only 8.

    Class access is lopsided: knight 357, barbarian 29¶

    Counting weapons in the types each class starts with, a knight can choose from 357 and a barbarian from 29. Barbarians (axe) get nothing new in 6 of 19 level bands (36–40, 41–45, 71–75, 76–80, 81–85 and 86–90). Counting the types each class trains cheaply instead (dashed lines), the gap narrows: knight 236, barbarian 204, cleric 151, mage 67.

    Method¶

    How these numbers are calculated
    • Weapons: 434 weapon prototypes; 433 at level ≤ 91; 420 obtainable (placed by at least one reset: shop stock, mob drop, floor or container). Level-0 weapons count as level 1.
    • Usable at level L = obtainable and weapon level ≤ L (a character can't wield an object above their level, act_obj.cpp:137).
    • Class affinity. Every class can learn every weapon from level 1 (SkillTables.cpp), but at different difficulty (the class rating): it's the creation-point cost and divides both practice gains (act_info.cpp:1604) and learn-by-use chances (Learning.cpp:52). Weapon skill % multiplies both to-hit and damage (fight.cpp:452, :472), so a class is effectively weaker with a hard-to-train type. Two views per class: start = types granted at creation by rom basics + <class> basics + <class> default (knight default includes weaponsmaster = all types); easy = types with difficulty ≤ 3.
    • Exotic weapons have no skill; every PC uses them at min(2 × level, 90)% (handler.cpp:108), so they're shown in supply figures but excluded from class comparisons.
    • Damage is the dice average n × (s + 1) / 2; skill, damroll, enhanced damage and weapon flags come on top. The cap is level/2 + 4 (+5% for two-handers), the rule immworth checks (entity_balance.cpp).
